SAFARI EXTENSION

Listen to the question.

ProtoBowl Voice follows the room's reveal timing. Turn on Natural flow for continuous sentence reading.

  1. In Safari Settings → Advanced, enable features for web developers.
  2. In Safari's developer settings or Develop menu, allow unsigned extensions. This developer build has no developer identity.
  3. In Settings → Extensions, enable ProtoBowl Voice and allow access to protobowl.com.
  4. Refresh your room, then start a question or click Voice to start listening.

Safari 18 or later · macOS 13 or later
Voice quality and timing depend on the installed system voice.
